发表于 2025-02-28

我们在hexo一篇中说过,我们需要用markdown来书写我们的博客
那么,什么是markdown?我们又该以什么形式书写markdown

formation of markdown

首先,markdown(以下以md代称)与c,cpp,py等格式相同,本质上都是txt换皮.你完全可以不用任何编辑器,直接以md格式写一个txt,然后simply把后缀改成md即可.
既然如此,你为什么还在这个板块?不快进刀md格式
并非如此
工欲善其事必先利其器.我们还是需要一个编辑器,来让我们在编辑时就能看到我们的效果
毕竟md不像word,ppt等可以直接在编辑时见到效果的格式,编辑器还是很重要的
我自己在使用vscode,万用开源文本编辑器,虽然在vscode中预览的格式与hexo中不是完全相同,但是仍是很好用的编辑器
