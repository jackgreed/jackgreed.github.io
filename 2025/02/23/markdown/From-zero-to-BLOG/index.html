如何闲着没事干记录生活

记从0开始利用hexo和GitHub pages部署个人博客

GitHub注册

要想在GitHub Pages上部署个人博客,至少你得先有一个GitHub账号,这部分不在赘述,相信你的能力

Github pages 申请

并非所有GitHub账号都自带Github Pages仓库.点击右上角+号,选择New repository创建新仓库
设置仓库信息为:
仓库名:必须是：你的GitHub用户名.github.io（比如你的 GitHub 用户名是 xiaoming，那仓库名就是 xiaoming.github.io）
选择 Public
不要勾选Readme.md,保持为一个空仓库
点击Create repository创建仓库

本地安装依赖

Hexo需要Node.js与Git,分别下载之,Node.js选择LTS版本

Hexo安装

在你的电脑上开辟一块区域,用来存放你的博客

  • 为方便叙述,这里以 D:\Blog为例
    打开powershell
    mkdir D:\Blog #创建文件夹
    cd D:\Blog #进入文件夹
    npm install -g hexo-cli #安装hexo
    hexo init #hexo初始化
    npm install #安装依赖

本地运行博客

在powershell下:
hexo clean #清除之前缓存
hexo g #生成网页
hexo s #在本地运行
然后访问http://localhost:4000
即可看到默认的博客页面

安装Github Pages插件

hexo需要一个插件,来讲网站部署到Github Pages上
在powershell中:
npm install hexo-deployer-git –save

配置_config.yml

最重要的是修改deploy部分,以将网站部署到GitHub Pages上
修改为:
deploy:
type: git
repo: git@github.com:你的GitHub用户名/你的GitHub用户名.github.io.git
branch: main
其余的有注释,只需中学英语水平即可,按自己喜好修改即可
然后记得保存

部署到Github Pages

在powershell中:
hexo clean
hexo g
hexo d #部署你的博客

  • 第一次使用需进行身份验证,需要ssh key,我们等下讲怎么做

访问你的博客

在https://你的GitHub用户名.github.io即可看到你的博客

身份验证

ssh key生成

先生成ssh key:
ssh-keygen -t rsa -b 4096 -C “你的GitHub邮箱”
再添加你的ssh key到GitHub上:
复制 ~/.ssh/id_rsa.pub 的内容
打开 GitHub SSH 设置，点击 New SSH Key，粘贴进去
重新部署即可

怎么写文章

在你的博客文件夹下找到此目录:source/_posts/
里面存放你的博客(md格式即可)
每次更改需重新部署一次
