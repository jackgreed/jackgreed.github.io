如何利用闲置”电脑”

记从0开始在树莓派上部署文件共享系统

系统安装

仍然使用上篇所提到的Ubuntu server ,如在安装上遇到问题,请参照上篇

软件安装

为实现一个文件共享系统,我们需要实现两方面的功能:客户端从服务器下载数据;客户端向服务器提供数据.

服务器提供下载

既然我们的服务器仅对内网服务,故流量并不会很大,可以简单一点,直接使用python自带功能即可

  • 为方便讲解,我们默认你ssh所使用的用户名为pi(即默认用户名)
下载示例

cd /home/pi && sudo mkdir web(web即为共享文件存放处) &&cd web
python3 -m http.server 8080 (8080端口任选,不冲突就行)

  • 至此下载部分完成,赞美python强大能力

文件上传

文件上传则复杂一些,考虑到用户可能不想等待文件传输过程,我们在传统的文件上传方式之外额外增加一项功能:仅传输bt文件,让服务器自己用bt文件下载,最大化利用服务器算力

传统文件上传

我们将使用FTP进行上传,好处是这对服务器的内存压力小,安装也简单.

上传示例

sudo apt install vsftpd -y #安装ftp软件
sudo nano /etc/vsfpd.conf #修改配置文件
将文件中以下几项修改(没有则自己增加)
anonymous_enable=YES
write_enable=YES
local_enable=YES
然后重启服务:
sudo systemctl restart vsftpd
服务器上的工作告一段落,接着是客户端方面
我们使用FileZilla,一款开源FTP软件进行文件上传(同样支持下载)
安装好后,服务器填树莓派ip地址,用户名填服务器用户名,密码填对应密码,端口为21即可开始传输文件

  • 可能遇到的问题:客户端没法将文件写入特定文件夹,这是由于权限不够导致的,请对此文件夹使用命令:
  • chmod 777 “$你的文件夹地址”
  • 此外,切记仅对无关系统组件的文件夹使用此命令(这是一个危险的命令,可导致服务器宕机)
bt上传

bt上传需另加组件,我们将使用Transmission来完成此工作

代码示例

sudo apt install transmission-daemon -y
sudo systemctl stop transmission-daemon
sudo nano /etc/transmission-daemon/settings.json
将文件中以下几项修改(没有则自己增加)
“rpc-enabled”: true,
“rpc-bind-address”: “0.0.0.0”,
“rpc-whitelist”: “127.0.0.1,192.168.*.*“, #谁被允许访问这里,分别是自己和同一内网下所有用户,保证安全
“rpc-authentication-required”: false, #内网就不需要密码了
“download-dir”: “/home/pi/web” #下载内容存放位置
关闭并保存文件
sudo systemctl restart transmission-daemon
完成
接着只需在客户端访问http://树莓派IP:9091/即可

我们屹立于巨人之上

我们,是高贵的Windows用户,抛开这下麻烦的安装,设置,我们可以直接添加网络驱动器
在你的服务器上安装samba
sudo apt install samba -y
配置文件权限(我们以/mnt/web为例)
sudo chmod 777 /mnt/web
编辑samba配置文件
sudo nano /etc/samba/smb.conf
在文件最后添加:
[share]
path = /mnt/web
browseable = yes
writable = yes
guest ok = yes
create mask = 0777
directory mask = 0777
public = yes
配置用户及密码
sudo useradd -M -s /sbin/nologin user
sudo smbpasswd -a user
然后自己配密码
重启samba服务
sudo systemctl restart smbd
sudo systemctl enable smbd
服务器配置完成
然后来到我们的Windows
在explorer中输入:\服务器IP\share
输入用户名,密码即可
