the MOO

发表于 2025-03-31

我们将创造一种全新的语言-MOO

语言小课堂

对于自然语言来说,最常见的构成是SVO(中/英文),或者SOV(日文),甚至OSV(还是日文)
它们,都太复杂了

  • 对于解析来说
    于是我们创造了MOO

MOO是什么?

M stands for Method && O stands for Object
即方法+对象1+对象2
任何一个句子,都有M+O+O构成
这是一种波兰式语法,显然,更加方便解析

  • 只要入栈就好了吗
    那么,什么是方法,而什么是对象?
    方法,很简单,只是一个二元谓词,返回一个对象或布尔值
  • 让我们先把返回值放一边
    对象,相反,很复杂,让我们用递归来定义
  • 一个名词,是对象
  • 一个布尔值,是对象
  • 一个代词,也是对象
  • 一个句子(M+O+O),是对象
    这就是为什么M需要一个返回值

简单的MOO示例

中文: 我吃饭
MOO: 吃我饭

  • 二元谓词后面所接对象的顺序,根据二元谓词本身的定义而定
    中文:小明和我踢足球
    MOO:踢(和(小明,我),足球)
  • 书写复杂MOO句子时最好加括号(不加也不会有歧义,这点以后再说),读就不需要了
    中文:我和小明踢球,导致我受伤
    MOO:导致(踢(和(小明,我),球),受(我,伤))

为什么不会有歧义

对于任意的M,都必须接收两个参数
不存在多参数情况
任何的MOO组合,都代表一个封闭的语句,即可化为O,递归处理,绝无多义性可能

语义拓展

然而自然语言不只有SVO,还有adj.,adv.等等
在MOO语法体系下,似乎无法实现这些成分
这时就需要拓展语法

何为拓展

众所周知,人类的自然语言都属于一个有限域,我们对其拓展,即是对有限域进行拓展,只需加入有限个元素,即可让我们的MOO语法得以表达其余成分

如何拓展

目前来看,似乎只需拓展2次,加入2个”保留字”即可,暂定为”de”,”ed”
当我们需要对一个O进行修饰,只需使用de(修饰词,修饰对象)即可
如:
中文:这是一朵漂亮的花
MOO:是(这,de(漂亮,一朵花))
English: This is a cute dog.
MOO: is(this,de(cute,a dog))
当我们需要对一个O进行限定,我们使用ed,ed(限定词,限定对象)
如:
中文:在所有人之中,你是最棒的
MOO:de(最棒的,ed(所有人,你))
English:you are the worst in class
MOO: de(worst,ed(class,you))
当我们需要对一个M进行修饰,我们使用de(修饰词,修饰对象)
你可能有疑问,不是M吗?怎么成为修饰对象
看一下例子,你就能明白
中文:我快速地吃饭
MOO:de(快速,吃(我,饭))
English:I run slowly.
MOO:de(slowly,run(I,NULL))

  • 这里出现了自然语言中的单元谓词,只需填NULL即可
    在MOO语言中,不可能出现单独的M,任何的M都会被包裹成一个O,所有可以用de
    对于限定M,同理,我们使用ed
    如:
    中文:五乘(在模10下)三等于5
    MOO:等于(5,ed(模10,乘(3,5)))
    English:in English,speaking needs practice
    MOO: need(ed(English,speak(NULL,NULL)),practice)
  • 对于部分0元谓词,我们直接填NULL即可
    至此,我们实现了MOO语言(至少是陈述句方面)

再次拓展

仅仅表述陈述句还不够,我们还需要让MOO语言能表达疑问句
这时我们需要再拓展一次(是的,只要一次)
我们再加入一个元素 “?”
我们知道,一个MOO语句的返回值要么是对象,要么是布尔值,显然,返回值是对象的MOO语句,无法成为疑问句
而对于返回值是布尔值的MOO语句,就可以被改造成疑问句

一般疑问句

一个MOO语句,若带有?元素,即代表其为疑问句,即请求对方做出回答,回答即是MOO语言为真时,?的一个解
让我们看一个例子:
中文:
你吃饭了吗?
是的
MOO:
是(吃(你,饭),?)
isTure(1,NULL)
相当简单,且回答不仅限此,任何恒真/恒假语句均可作为一般疑问句的解

其他疑问句

然而,我们有些时候,不只询问真假,还需询问一个或多个对象
也很简单
如:
中文:
你的内裤是什么颜色?
内裤是白色.
MOO:
是(de(你,内裤),ed(?,颜色))
是(内裤,白色)

总结

我去,MOO,伟大,来源于密码学课上的胡思乱想,花了40分钟完善,目前来说,还算ok吧(大概)
